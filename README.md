# Text Focus

### Interactive Cursor-Based Text Spotlight Effect

**Text Focus** is a creative frontend animation that highlights text using an interactive circular spotlight controlled by the mouse cursor. It creates a unique visual experience by keeping the background text blurred while revealing a sharp, focused version inside the spotlight.

**Live Demo:** [Text Focus](https://akashmadavi2001.github.io/Text-Focus/)

---

## Features

- **Interactive Spotlight:** A circular spotlight follows the mouse cursor.
- **Focus Effect:** Reveals clear and sharp text within the spotlight.
- **Blur Animation:** Keeps the surrounding text blurred for a unique visual effect.
- **Mouse Tracking:** Dynamically updates the spotlight position based on cursor movement.
- **Minimal Design:** Clean, modern, and visually engaging interface.
- **Lightweight:** Built using pure HTML, CSS, and JavaScript without external libraries.

---

## Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling, blur effects, clipping, and animations.

## How It Works

1. The webpage displays text in two overlapping layers.
2. The background layer applies a blur effect.
3. The foreground layer uses CSS `clip-path` to create a circular viewing area.
4. JavaScript tracks the mouse cursor position.
5. CSS variables dynamically update the spotlight position.
6. The focused text becomes visible as the spotlight moves.
