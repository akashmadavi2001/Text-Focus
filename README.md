# Text-Focus

Text Focus Animation is a frontend interaction that dynamically emphasizes specific text as it enters the user’s focus. Using HTML, CSS, and JavaScript, the animation can smoothly change properties such as opacity, color, scale, blur, or position to create a focused reading experience.

How it works:

HTML defines the text elements.
CSS controls the animation, transitions, and visual styling.
JavaScript detects user interaction or scroll position.
When the text reaches the focus area, an animation is triggered.
The focused text becomes prominent while surrounding text can remain slightly faded or blurred.

Example effect:
As the user scrolls down a webpage, each sentence gradually changes from low opacity → sharp and highlighted → low opacity, creating a cinematic text-reading effect.
